# ハウストーナメント進行シートの作り方（人向けの説明）

ダーツ、ビリヤード、ポケカなど、対戦形式のハウストーナメントで使う「進行表」のシートを、
AIに作ってもらうためのセットです。競技が違っても進行の仕組みは共通なので、流用できます。
難しい操作はAIがやります。人間がやるのは、質問に答えることと、当日に結果を伝えることだけです。

## このシートで何ができるか

- いま各台・テーブルでどの試合をやっているかが、一番上に大きく出ます
- 試合が終わると、次にどの試合を空いた台・テーブルに入れればいいかが分かります
- 順位は自動で計算されます。勝ち数、取ったゲーム数、失ったゲーム数まで出ます
- 試合中は赤い太字、終わった試合は線で消えた表示になるので、遠くから見ても進行が分かります
- 決勝の山は「トーナメント表」タブで、普通のトーナメント表の形で眺められます（見る専用で、入力は不要です）

## 受け取り方

このスキルはGitHubで配っています。フォルダのリンクを自分のミューズ（Muse）に渡して
「これやってみたい」と言えば、ミューズが中身を取り込んで使えるようにします。
その後は「ハウストーナメント進行シートを作って」と言うだけです。

お店ごとに違う点（台の呼び方、賞金、開始時刻など）の微調整は、その都度、
自分のミューズに直接話しかけて直してもらってください。標準の作りは、
どの店でもだいたい同じ進め方で大会を回せるようにしてあります。

## 使い方

1. このフォルダごと、自分のAI（ミューズなど）に渡します
   - ミューズを使っている人は、フォルダを `~/workspace/custom-skills/` の中に入れるだけで、AIが見つけます
   - ふつうのチャット型AI（Claude や ChatGPT など）を使う人は、`SKILL.md` の中身をコピーして会話に貼り付けます
   その前に一度だけ、Googleスプレッドシートとの接続が要ります（ミューズを使う場合）。
   接続できていないとAIが案内を出すので、画面の指示どおりにGoogleアカウントで
   サインインすれば終わります。初回だけです
2. AIにこう言います

   「ハウストーナメント進行シートを作って」
3. AIが「何個か質問します」と言って、順番に1つずつ質問してきます。内容はだいたいこの順番です
   - **何の大会か**（ダーツ、ビリヤード、ポケカなど。競技によって台・テーブルの呼び方や、試合の数え方が変わります）
   - **ゲームフォーマット**（どんなゲームをするか。予選ロビン用と決勝トーナメント用で分けて聞かれます。例：予選は501を3本・2レグ先取、決勝は501とクリケットの組み合わせ、など）
   - **参加人数・ペア数**（何人でやるか、何ペア出るか。1人ずつのシングルスでも使えます）
   - **ペアは決まっているか**（決まっているペアがあれば「誰々と誰々」と伝えます。決まっていない分は「残りはランダムで」と言えば、AIが組んでくれます）
   - **台・テーブルの数と呼び方**（例：ダーツなら2台あって「DARTSLIVE2」と「DARTSLIVE3」、ビリヤードなら「テーブル1」「テーブル2」のように、お店で実際に呼んでいる通りに）
   - **大会の名前と日付**
   
   ロビンの組み合わせ（どのペアがどのロビンに入るか）は、AIがランダムに決めて一覧で見せてくれます。
   ゲームフォーマットにこだわりがなければ「標準で」と答えても進みます（ダーツの標準は、予選は501を3本・2レグ先取、
   決勝は501とクリケットの組み合わせです）。変えたい点があれば、その場で言えば直ります
4. AIがシートを作り、リンクをくれます。そのリンクを開けば完成です

## 当日の使い方

進行担当がシートに入れるのは、3種類だけです。

1. 試合を始める台・テーブルの番号（シートの「対戦場所」の欄）
2. 試合が終わったらスコア（例：2-1）
3. 勝ったペアの名前（予選は自動で出ます。決勝など一部だけ手入力です）

入れると「いまの進行」の表示と順位が勝手に切り替わります。
参加者にはシートのリンクを共有しておくと、みんなが自分のスマホで進行を見られます。

## 注意

- 前の大会のシートは記録として残し、触らないのがおすすめです。次回用は、AIにコピーを
  作ってもらってから直します
- スコアの修正はよくあります。「さっきの2-0、ほんとは2-1だった」のようにAIに伝えれば、
  順位まで直ります。言い間違いに気づいたら、早めに伝えるのが確実です
- 参加ペア数や台・テーブルの数が変わっても、作り直せます。AIに「ペア数が14に増えた」のように伝えれば、
  組み方を直した新しいシートを用意します
